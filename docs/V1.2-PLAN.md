# V1.2 development history

## Bug fixes queued

- Local DEV.6 encodes the selected keep range to respect trim markers between keyframes, validates the saved duration, and shows encoding progress. The preview pauses at the end marker.

- Local DEV.7 applies the selected markers to Remove selected middle, joins the kept video and audio in one encode, and verifies the saved duration before replacing a file.

- Local DEV.5 replaces the fixed 768 MiB video buffer ceiling with a budget based on available RAM. Longer clips at Very High are possible with enough memory. Home and Alt+Z display the effective limit while preserving the selected duration.

- Local DEV.4 adds a scrollable Patch Notes window for the first launch after an update. Fresh installs establish a version baseline. DEV.8 includes Zaid's notes and highlights the WGC announcement.

- Local DEV.9 gives Patch Notes a FLICK header, grouped entries, and a custom scrollbar, and clarifies the capture and trimming terminology.

- Local DEV.10 restores Zaid's wording with technical corrections, groups the notes by category, collapses QOL and bug fix developer notes, and opens Home on launch.

- Local DEV.3 adds an opt-in Windows Graphics Capture (Beta) backend in Settings. Pause replay, select the backend, and resume. DXGI remains the default and is used for the session if WGC cannot start or fails to produce its first replay fragment within eight seconds of launch. Windows controls the capture border. Windows 11 gameplay and true exclusive fullscreen still require hardware validation.

- Local DEV.8 adds a two-minute auto-resume setting, off by default, with a notification after recording starts. The build version appears in the Home footer.

- Lock quality profiles and capture FPS in Home and Alt+Z until replay has fully paused. Reject delayed control events during recording/startup/recovery and apply paused changes only when replay is resumed.

- Prevent saving a replay while replay is paused, stopping, starting or recovering. Disable the Home and sidebar save controls and the tray save action; reject save-hotkey requests and direct engine saves while paused. Changing the paused replay duration must not allow old buffered footage to be saved. Saves already accepted before pausing may finish before recording stops.

Capture-setting regressions (Windows, .NET 10): after building the app, run
`dotnet run --project tests/CaptureSettings/Tests.csproj -- <absolute-build-folder>`.
These tests use an isolated settings model and simulated engine states; they do not start recording.
