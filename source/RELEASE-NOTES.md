# FLICK V1 - v1.0.0

FLICK's first public release for Windows x64.

- Instant replay with up to five minutes of history.
- Five quality profiles with 30 and 60 FPS recording targets.
- Separate audio tracks and configurable recording shortcuts.
- Full-resolution screenshots with Alt + 0.
- A clip library with cached previews, playback, trimming, and middle-section cuts.
- Discord compression and configurable local storage.
- A sidebar, optional status HUD, and customizable accent colours.
- A manual update button and one background update check per launch.

Available as a per-user MSI installer or portable ZIP, with corresponding source
and SHA-256 checksums. See the README for installation, controls, and privacy details.
